- `.github/workflows/import-reviewed-product.yml`: импорт одобренной карточки и фото из `data/product-import-request.json`, проверка каталога, commit, вызов автономной сборки.
- `.github/workflows/build-offline.yml`: локальные фотографии и SVG-логотип встраиваются в автономный HTML.
- `.github/workflows/validate-catalog.yml`: проверка JSON, ID, связей, дат и изображений.
- Все три workflow разрешены для `finds-v2-image-test` и `main`.
- Одноразовые диагностические workflow для EMOS/Metabo, проверки dispatch и миграции старых фотографий удалены из тестовой ветки.
- Исходные данные: `data/products.json`. Тестовые/архивные ветки не удалять.

## Перед переносом
1. Проверить актуальные GitHub Actions после последних изменений workflow. Проверки кода не заменяют реальный запуск.
2. Проверить GitHub Pages и PWA именно на production origin после отдельного разрешения на перенос. Успешный автономный HTML не доказывает работу PWA.
3. Сохранить финальный снимок HEAD тестовой ветки после всех правок.

5. После переноса проверить загрузку каталога и фотографий, service worker, импорт карточки и автоматическую пересборку на `main`.

## Принципы
FINDS — личная библиотека удачных находок. Пользователь сообщает о товаре; поиск характеристик и фотографии, подготовка заявки и импорт максимально автоматизированы. Не перезаписывать существующие фотографии или карточки без подтверждения. Новые товары по умолчанию сверху.
