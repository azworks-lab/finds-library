# Правила библиотеки победителей

Выбранный или купленный товар уже прошёл проверку при обсуждении. Повторная заводская проверка для включения в каталог НЕ нужна.

- Включать только окончательно выбранные и купленные товары.
- Использовать известные модель, артикул и характеристики; неизвестное не выдумывать.
- Повторно исследовать только при существенном поводе: несовместимость, неправильная модификация, серьёзный дефект или изменение ключевых параметров.
- Незначительные расхождения веса, округления и другие не влияющие на работу мелочи игнорировать.
- Для новой покупки проверять текущие цену и наличие; историческую цену не считать текущей.
- Не показывать технические статусы проверки в пользовательском интерфейсе.

## DEPO

При новом выборе, если данные DEPO противоречат другим источникам по важным характеристикам, сверять EAN/MPN с производителем. Это НЕ создаёт обязательства повторно проверять уже выбранных победителей.

## Служебные данные

EAN, MPN и ссылки можно хранить, если они известны или нужны для решения значимой проблемы. Статусы проверки не являются обязательными для публикации карточки.
