# Проверка идентичности и характеристик товара

## Специальное правило для DEPO

Описание товара в DEPO не считается достаточным подтверждением технических характеристик.

1. Идентифицировать товар по EAN/GTIN (штрихкод), если известен.
2. Сверить заводской артикул производителя (MPN), модель и вариант исполнения.
3. Сопоставить данные с официальным каталогом, техническим паспортом или инструкцией производителя.
4. При расхождениях перепроверить независимые каталоги и карточки других продавцов.
5. Цену, наличие и условия получения проверять отдельно у продавца на дату проверки.

## Правила качества данных

- Не подменять заводской артикул внутренним артикулом магазина.
- Не считать похожие фотографии доказательством идентичности модели.
- Не приписывать товару характеристики соседней модификации.
- При расхождении источников сохранять замечание и ссылки на источники.
- Не заполнять неизвестные поля догадками.
- Не считать найденную в прошлом цену актуальной.
- Сохранять EAN/GTIN, MPN, источники спецификации и дату проверки, когда они известны.

## Статус проверки

- `verified` — идентичность и ключевые характеристики подтверждены производителем.
- `partial` — часть характеристик подтверждена, часть не установлена.
- `pending` — ожидается проверка или идентификация.

Статус проверки не заменяет статус товара «Куплено»/«Выбрано».
