# FINDS — правила разработки и каталога

Этот файл — постоянная инструкция для всех будущих изменений FINDS. Перед правкой поиска, импорта, карточек или офлайн-сборки сверяйся с ним.

## 1. Поисковый индекс — только собственные признаки товара

Поиск по каталогу должен использовать **только**:
- `name` — название и модель;
- `brand` — фактический производитель/бренд;
- `sku` — артикул;
- `category`, `subcategory` — собственная классификация;
- `specs` — собственные технические характеристики;
- `tags` — функциональные и предметные метки, относящиеся к самому товару.

**Запрещено включать в индекс:** `note`, `related`, `details` (особенно сведения о совместимости), `sourceNote`, а также любые текстовые поля с историей монтажа, связанными товарами, чужими брендами и контекстом использования. Эти сведения могут отображаться в карточке, но не должны влиять на результаты поиска.

Пример: hansgrohe Logis 100 установлен на раковину IKEA. Запрос `IKEA` не должен находить смеситель. SCHELL, упомянувший hansgrohe в заметке, не должен находиться по `hansgrohe`. Нельзя «чинить» это удалением полезных заметок: устраняется источник ложных совпадений в поисковом индексе.

## 2. Смысловые функциональные метки

Метки отражают **реальный функционал самого изделия**, независимо от слов в названии. Например, `умный дом` должны иметь относящиеся к умному дому Sonoff, IKEA BILRESA, SILVERGLANS, MYGGSPRAY и Tuya LED-диммер. Не присваивай `умный дом` обычной мебели только из-за наличия в комплекте умного устройства. Не присваивай бренды сторонних изделий как метки совместимости.

Для новых товаров заполняй `tags` по тем же правилам; проверяй, что бренд, категория и модель заполнены корректно. Сохраняй полезные связи отдельно в `related` и заметках.

## 3. Релевантность и регрессионные тесты

Приоритет выдачи: (1) название/бренд, (2) артикул/характеристики, (3) категория/подкатегория, (4) функциональные метки. Внутри уровня применяется выбранная пользователем сортировка.

Контрольные запросы для текущего набора 30 товаров:
- `IKEA` → 8 товаров IKEA, **без hansgrohe**;
- `hansgrohe` → только hansgrohe Logis 100, **без SCHELL**;
- `Sonoff` → 3 товара Sonoff, **без IKEA**;
- `Умный дом` → 7 релевантных устройств, включая IKEA;
- `Датчик движения` → ORNO OR-CR-282 и IKEA MYGGSPRAY.

Количество может измениться с ростом каталога: проверяй **смысловую правильность** результатов, а не слепо фиксированное число. При изменении кода проверяй онлайн-приложение и сгенерированный `library-offline.html` — логика поиска должна совпадать.

## 4. Процесс изменений

Разрабатывай в отдельной ветке, показывай изолированный предпросмотр и не переноси в `main` без подтверждения пользователя. Не ломай работающую PWA, фотографии и автономный HTML. После согласованного объединения в `main` проверяй GitHub Actions сборки офлайн-версии и фактическую работу в Chrome на Android.

## 5. Источник истины

Каталог — `data/products.json`; интерфейс и поиск — `index.html`; офлайн-копия — генерируемый `library-offline.html`. Не редактируй сгенерированный офлайн-файл вручную ради постоянного исправления: меняй исходники и пересобирай.
