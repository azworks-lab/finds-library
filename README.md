# Библиотека удачных находок — версия 2.0

Личный каталог **только утверждённых решений**: купленных и выбранных товаров. История сравнений, проигравшие модели и открытые кандидаты остаются в чатах, не в библиотеке.

## Интерфейс
Сайт/PWA с навигацией **Главная → раздел → подраздел → карточка**. Поиск, фильтры, раскрытие карточек по нажатию. Shortcut на главной — три последних утверждённых решения.

## Разделы
- Инструменты
- Электрика и освещение (включая лампы IKEA GU10)
- Мебель и интерьер (включая IKEA)
- Сантехника и ванная
- Бытовая техника
- Отопление и вентиляция

## Статусы
- **Куплено**
- **Выбрано**

## Карточка товара
Конкретная модель; артикул; ключевые характеристики; магазин/место покупки; цена или бюджет; ссылка; дата проверки цены; статус; краткий вывод, почему выбрали.

## Принципы
- Не выдавать старую цену за текущую.
- Не добавлять отклонённые товары и незавершённые сравнения.
- Не дублировать модели.
- Развивать библиотеку постепенно, сохраняя согласованную архитектуру.
- После записи проверять чтением фактический результат.
